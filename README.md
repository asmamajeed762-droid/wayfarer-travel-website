# wayfarer-travel-website
Travel & Tourism Website 

A premium and responsive travel website designed to showcase beautiful island destinations through cinematic visuals, elegant layouts, and a smooth browsing experience.

#  Features

- Cinematic video background in the hero section
- Beautiful destination cards
- Maldives, Bora Bora, Santorini and Bali destinations
- Golden-hour inspired design
- Responsive layout for mobile and desktop
- Smooth animations and transitions
- Travel planning and destination exploration sections
- Elegant typography and modern UI
